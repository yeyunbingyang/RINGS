# Changelog

## v0.1 — 2026-11-18

### Added
- Unified Execution Library page for Task and Habit management.
- Execution views: All, Ordinary Tasks, Habits.
- Task status filters, search, detail panel, subtasks and quick status actions.
- Habit repeat rules, quantity targets, daily occurrence status, pause and resume actions.
- Candidate Pool with ten categories and independent lifecycle filters.
- Candidate quick capture, search, details, notes, tags, external references and follow-up date.
- Candidate lifecycle actions and a conversion demonstration for Candidate → Task.
- Responsive layout for desktop and narrow screens.

### Notes
- Static prototype only; uses in-memory demo data.
- No backend, database, API, authentication or persistence.
- Candidate → Goal / Direction / CalendarEvent conversion forms are not implemented.
- Embedded JavaScript syntax check passed.
- Browser automation, responsive visual inspection and accessibility validation are pending.
