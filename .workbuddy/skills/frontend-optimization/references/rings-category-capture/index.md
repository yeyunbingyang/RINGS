# RINGS 候选事项按分类快速捕捉

用户已确认合并方案 1 和 2，并要求增加双击提示。效果图统一用「想法」作为示例。

- 用户希望从候选事项分类直接进入对应的快速捕捉，提出双击分类，也接受其他交互方案。
- 调整前单击分类只筛选，右上角快速捕捉打开后默认「备忘」。关联规则为 R04，筛选分类和保存分类使用同一套定义。
- [方案 1 · 双击分类](rings-category-capture-1.png)单击筛选，双击打开并预选该分类。界面紧凑，建议保留可见的键盘入口。
- [方案 2 · 顶部按钮随分类变化](rings-category-capture-2.png)当前为想法时显示「捕捉想法」，全部分类时显示「快速捕捉」。入口沿用原位置，状态清楚。
- [方案 3 · 分类旁加号](rings-category-capture-3.png)在当前分类旁显示独立加号，可在同一区域完成筛选与新建。
- 三种方案打开弹窗后均可改选分类，保存时使用弹窗中的最终选择。

实现后，分类栏下方显示「双击分类可快速捕捉」。单击只筛选，双击具体分类或点击右上角的分类按钮可打开弹窗。已验证两条路径、切回全部分类、改选分类后保存和读回。[候选事项页面](rings-category-capture-live-page.png) · [预选分类的弹窗](rings-category-capture-live-dialog.png)
