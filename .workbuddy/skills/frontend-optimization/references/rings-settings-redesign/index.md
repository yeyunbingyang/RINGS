# RINGS 工作台设置重构

用户要求移除侧栏底部重复的「自定义导航」，并重构设置面板。侧栏入口移除后，仍可从「设置」配置导航与快捷操作。设置页目前将名称、调度、显示、备份与导航堆在一页，两组保存按钮容易混淆。

参考 R02、R05、R08。效果图使用示例设置。用户确认方案 2，已实现。

- [方案 1 · 左侧二级目录](rings-settings-redesign-1.png)便于频繁在设置分类间切换，右侧只显示当前组，并把保存按钮放到本组。
- [方案 2 · 顶部三页签](rings-settings-redesign-2.png)将工作区与偏好、导航与快捷操作、数据与恢复分开，保留内容宽度。推荐。
- [方案 3 · 设置总览卡片](rings-settings-redesign-3.png)先展示各组的当前值和入口，每组进入独立面板。

已用独立工作台验证三个页签、键盘切换、草稿保留、分组保存与刷新读回。顶部按钮直达快捷配置。偏好中的每周起始日和默认任务时长已接入实际操作。
