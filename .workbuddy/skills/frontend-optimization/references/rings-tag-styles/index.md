# RINGS 全项目业务标签样式

用户希望美化详情中的「开发」「产品设计」「GPT」小标签，并将样式推广至整个项目同类标签。目前候选事项列表把标签混在摘要文字里，详情和快速捕捉分别使用不同的外观。对应规则为 R02、R04、R05。

- [方案 1 · 中性色圆角标签](rings-tag-style-1.png)采用统一的中性浅底与 # 标记，适合密集列表。
- [方案 2 · 低饱和分色](rings-tag-style-2.png)同名标签跨位置保持同色，适合快速扫读。推荐。
- [方案 3 · 统一底色与彩色圆点](rings-tag-style-3.png)用色点识别标签，文字和底色统一。

三个方案保留快速捕捉的已选及常用分栏，区分可选、已选可移除和只读展示，分类和状态徽标沿用业务语义。效果图使用示例数据。用户确认方案 2，已实现。
