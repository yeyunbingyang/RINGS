# RINGS 收藏资料与清单优化

用户希望整理本地文件或网站时，在一条清单下集中保存多份文件、来源网址和归档位置，同时保留整条事项的公共资料。

- 关联规则为 R04、R05、R07、R08。
- 已确认事项和清单都能挂资料。清单默认折叠，显示文件、来源引用和整理目标的数量。添加文件与添加引用分开，引用可按行批量添加。
- 资料可移动归属。删除带资料的清单前提示数量，确认后把资料移回事项级。文件限单个 1 MB、单事项合计 3 MB，大文件可记录路径。
- 转为执行任务时复制清单文字为子任务，从任务的来源入口可查看原候选事项及其资料。
- 已在 Windows 的桌面浏览器使用独立工作台验证多文件选择、拖入、批量引用、路径和网盘目标、移动归属、删除回收、保存刷新、附件下载内容、附件限额和转任务回看来源。另通过设置页验证旧版备份导入。修复了刷新前旧页面写回覆盖导入内容的问题。
