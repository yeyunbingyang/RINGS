# RINGS 候选事项编辑面板

用户已选方案 2，已实现。依据 R01、R02、R05、R08。现面板宽约 720 像素，备注只露出少量文字，相关字段分散，底部挤在一排的多个操作被迫折行。

- [方案 1 · 宽版双栏](rings-candidate-edit-1.png)集中备注、来源、清单和资料，适合边看边改。推荐。
- [方案 2 · 分组页签](rings-candidate-edit-2.png)把基础信息与标签、备注与来源、清单与资料分为三页，页签之间保留草稿。
- [方案 3 · 单栏折叠](rings-candidate-edit-3.png)默认看标题、标签和备注，按需展开清单和资料，适合快速修订。

三案均保留已确认的彩色业务标签、清单与资料的层级。底部主操作为「保存修改」，任务、目标和日历事件归入「转为…」，归档和删除归入「更多操作」。分类项较多时使用可搜索选择，少量状态直接展示。
