# RINGS 顶部快捷操作与收藏资料

用户确认复用截图中的快速捕捉表单，隐藏分类选择并保留文件资料区。顶部采用方案 2 的浅色配色。三张桌面效果图采用同一组示例数据。

- 用户反馈顶部快捷操作缺乏色彩区分，收藏资料表单与预期不符。
- 顶部快捷操作使用统一白底、同一默认圆点，收藏资料另开轻量表单，标签用逗号输入，备注单独排布。保存已归入「资料」类候选事项。现行需求允许名称先保存，链接或路径后补。
- 参考 R02、R04 和 R05。收藏仍归入候选事项的资料分类。
- [方案 1 · 白底按钮与轻量表单](rings-resource-1.png)只给图标着色，保留纵向资料表单，标签改为点选。
- [方案 2 · 浅色快捷按钮与分区收藏](rings-resource-2.png)按钮按用途配浅色，标签沿用多选，来源和备注集中在上下文。
- [方案 3 · 突出资料入口并复用快速捕捉](rings-resource-3.png)收藏入口预选资料，复用分类、标签、清单和资料区。

## 实际验收

顶部「收藏资料」保留创建类型、已选和常用标签、备注、清单和资料区。候选事项固定归入「资料」。已验证选择文件、拖入文件、粘贴引用、保存与重载后读取。下载按钮生成了正确的文件名与内容，自动化浏览器取消了下载落盘，普通测试链接也有相同行为。[实际运行截图](rings-resource-files-live.png)
