# RINGS 快速捕捉的自定义标签

用户已确认方案 3，已实现。效果图使用同一组示例标签。

- 用户反馈：标签下方的自定义输入栏占满一行，添加入口离已有标签较远，已选标签需要更明显的区分。
- 关联规则为 R02、R04、R05。标签库采用可搜索下拉时同时参考 R08。
- [方案 1 · 同行添加](rings-custom-tag-1.png)平时只显示添加入口，展开后在标签末尾显示短输入框。适合当前快速捕捉，减少表单占位。
- [方案 2 · 搜索与新建合一](rings-custom-tag-2.png)在同一个面板搜索已有标签或创建新标签。适合标签库逐渐增多。
- [方案 3 · 已选与常用分栏](rings-custom-tag-3.png)分开展示选中状态和常用入口。适合单条事项带多个标签的情况。
