# CAP-02 规划能力

> 所属层：规划层 Planning  
> 优先级：P0  
> 状态：核心实体与边界已纳入 PRD；v0.8 规划工作区原型首轮完成（prototype_only）；指标口径已形成设计方案，待用户评审；正式持久化未实现。

## 1. 能力目标

帮助用户明确长期发展方向，将方向转化为可衡量目标，再把目标拆分为可管理的阶段，并与执行任务关联。

## 2. 子能力

| 编号 | 子能力 |
|---|---|
| CAP-02-01 | Direction 发展方向管理 |
| CAP-02-02 | Goal 目标管理 |
| CAP-02-03 | 目标衡量指标和完成条件 |
| CAP-02-04 | Stage 阶段拆分与排序 |
| CAP-02-05 | Goal / Stage 与 Task 关联 |
| CAP-02-06 | 目标进度自动计算（增强） |

## 3. Direction（发展方向）

定义：长期希望投入、提升或发展的领域。

示例：职业发展、AI 技术能力、软件工程、英语能力、健康管理、个人创作。

规则：
- 不强制设置截止日期。
- 可以关联多个 Goal。
- 可以只有描述，不立即创建 Goal。
- 可暂停或归档，不影响历史 Goal。

## 4. Goal（目标）

目标分为两类。

- 成果目标有明确交付物或达成条件，可以记录完成条件。阶段完成比例用于观察推进情况，用户确认成果后标记完成。
- 持续目标用于长期维护或建设，允许不断添加阶段和任务。阶段全部完成时仍保留当前目标状态。展示当前阶段、已完成和待推进阶段数，可以暂停或归档。持续目标可只指定开始日期，阶段和任务可各自安排时间。

建议字段：名称、说明、所属 Direction、指标类型、当前基线、目标值、单位、开始日期、目标期限、完成判定条件、状态和当前进度。

指标类型建议：数值、里程碑、布尔完成、自定义。最终类型待决策。

规则：
- Goal 表示结果，不等同于 Task。
- 目标进度不能简单等于任务完成率。
- 有量化指标时优先依据指标计算。
- 里程碑型目标可参考 Stage 完成情况。
- 用户可以手动更新进度。

## 5. Stage（阶段）

定义：实现一个 Goal 过程中划分的阶段性工作过程。

示例：找到一份合适的新工作：
1. 职业定位。
2. 求职准备。
3. 投递与面试。
4. Offer 评估与入职。

建议字段：goal_id、title、description、sort_order、start_date / due_date（可选）、exit_criteria、status / progress。

规则：
- 一个 Goal 可以有多个 Stage。
- Stage 可以关联多个 Task。
- Stage 可以没有固定时间。
- Stage 应有可判断的完成条件或交付结果。
- Stage 完成不等于 Goal 完成。
- 阶段状态可直接编辑为未开始、进行中、受阻或已完成。任务、阶段和目标分别确认完成。
- 阶段支持独立标签、清单与资料，可关联未归属或同目标的任务。删除阶段时，同目标任务改为直接归属目标，清单及资料移入目标。
- Task 可直接关联 Goal，不强制必须归属 Stage。
- 桌面规划页提供目标与阶段搜索。目标和子阶段各有「手动顺序」「优先级」，均支持高、中、低三级。手动顺序下可拖动或用上下方向键调整，保存后刷新仍保留。按优先级从高到低，同级沿用手动顺序。目标继续支持最近创建、完成进度和目标日期排序。
- 可在阶段列表或阶段详情直接新建执行任务。表单预填目标和阶段，确认保存后才创建任务。
-新建任务时，可关联目标在 6 项以内直列，7 项起提供可搜索的下拉。

## 6. 页面建议

- Direction 列表 / 详情。
- Goal 列表 / 详情。
- Stage 时间线或阶段看板。
- Goal 详情中显示指标、阶段、关联任务和补充资料。
- Goal 详情可直接打开关联任务的执行详情。
- 目标可从卡片双击或详情按钮重新编辑，支持标签、备注、清单和分组资料。
- 首页仅展示目标摘要和里程碑；完整编辑在规划工作区。

## 7. 核心流程

```text
创建 Direction（可选）
    ↓
创建 Goal
    ↓
定义目标指标、期限和完成条件
    ↓
拆分 Stage
    ↓
为 Stage 创建或关联 Task
    ↓
Task 进入执行层
    ↓
回看 Stage 结果和 Goal 指标
```

## 8. 验收要点

- [ ] Direction 可独立存在，不强制期限。
- [ ] Goal 可设置衡量指标和完成条件。
- [ ] Goal 可拆分多个 Stage。
- [ ] Stage 可以关联多个 Task。
- [ ] Task 可以直接关联 Goal。
- [ ] 不强制所有 Task 归属 Goal。
- [ ] Stage 完成不自动等于 Goal 完成。
- [ ] Goal 进度口径可解释，不简单等于任务完成率。


## 9. Goal 创建时的可选 Stage

创建 Goal 时允许用户选择是否同时建立子阶段（Stage）。Stage 可以逐条添加、编辑、删除和排序；不建立 Stage 不影响 Goal 保存。Stage 是 Goal 的规划结构，不因创建而自动生成 Task。

原型状态：prototype_only；Stage 与 Goal 的持久化关系仍需在正式数据层实现。


## 10. v0.8 指标与进度细化

原型提供四种 Goal 衡量方式：
- 数值指标：按基线、当前值和目标值计算，支持递增 / 递减。
- 里程碑：已完成 Stage 数 / Stage 总数；各 Stage 当前等权。
- 布尔结果：由用户明确确认是否达成。
- 自定义进度：用户手动维护 0–100%。

Goal 进度与关联 Task 完成率分开显示；Task 完成率不参与 Goal 进度计算。Stage 全部完成不自动关闭 Goal。没有 Stage 的里程碑目标显示 0%。

以上是 v0.8 原型方案，Stage 加权、Goal 多指标、历史快照和自动进度策略仍待评审。

## 桌面规划工作区

「目标拆解」是已归属任务的管理入口。任务按目标直属或阶段归属展示，子任务跟随父任务。「未归属与习惯」补充管理尚无目标的普通任务及习惯。从调度或挂起事项打开某项任务时，直接显示该任务的详情。

在笔记本视口（宽度 1071 至 1370 CSS 像素），标题、四张统计卡和视图操作保持同排，目标列表和详情继续左右并列。进一步缩窄窗口时，统计卡可完整换到下一行。

主导航「规划」默认打开列表视图。桌面宽度下，活跃方向、进行中目标、近期阶段节点和目标关联任务四项统计位于页面标题与「新建目标」之间。窄屏时，统计卡片换到标题区下方，仍位于视图切换栏上方。目标列表采用窄栏，显示目标类型、优先级、日期、标签和进度。发展方向筛选和管理位于规划页头。当前目标在列表中有「已选」标记。右侧按所选顺序连续展示阶段，宽屏在卡片内并排显示阶段信息和任务，窄屏上下排列。各阶段直接显示任务与子任务，可勾选完成或恢复。方向可以独立创建、编辑、暂停或归档，归档后保留目标和任务关系。列表可按方向、未归属、状态及关键词筛选。选定顶部方向后，可以在该方向下新建目标，或关联未归属和其他方向的已有目标。方向筛选包含「全部方向」和「未归属方向」，总选项达到 7 项时使用可搜索选择。目标编辑时也可变更方向，阶段可直接创建关联任务。目标详情按内容呈现，零阶段时显示新增入口，至少有两条阶段时显示排序。成果目标的阶段进度按阶段完成数计算，持续目标展示阶段推进状态。

未来 7 天无安排时，在目标列表标题处显示单行提示。有安排时，在目标列表下方显示可双击编辑的安排。

新建和编辑目标共用紧凑表单。「目标类型」「优先级」「目标状态」优先同排，空间不足时按整组换行。标签在固定选项之后、所属方向与日期之前。表单打开时直接展示最多 6 个已有标签，按工作台使用次数排序。同一标签点击可选中或取消，其他标签可通过搜索选择。

目标表单中的「上下文」「完成条件」「子阶段」在桌面宽度下并排显示，便于一次补齐说明、验收标准和阶段拆解；持续目标隐藏完成条件后，剩余区域自然铺满。窗口变窄时分列换行，字段内容与阶段管理保持不变。

当阶段关联的任务或子任务有进行中或已完成项时，原为未开始的阶段显示进行中，可添加到独立的「挂起事项」页。手动受阻或已完成的阶段保留所选状态。阶段卡片可通过状态下拉在未开始、进行中、受阻和已完成之间切换。阶段卡片收起时即可加任务、关联、编辑、完成或删除，进行中的阶段另外显示挂起入口。展开后查看阶段说明、日期与资料。目标直属任务单列。备注、完成条件与资料可按需展开。

阶段任务和目标直属任务可通过行内「编辑」或双击名称打开任务表单。子任务也有编辑入口，打开时定位到对应名称。父任务行的「＋ 子任务」在原地展开输入框，保存后立即在该父任务下显示。

挂起栏只显示待推进的任务和子任务。已完成、已取消、已废弃及已归档的任务隐藏。阶段卡显示可换行的阶段名称，并分别标明方向与目标。单独挂起的任务卡显示所属方向及已有的目标、阶段和父任务。阶段卡内的父任务和单独挂起的父任务都可直接新增子任务。

可执行的任务和子任务可从规划列表直接开始或排期。开始时记录实际开始时间，将事项设为进行中，并定位到调度页当天的实际执行时间线。排期时先在规划页确认时间，默认填入下一时间格和任务的预计时长。已有尚未结束的排期时直接打开该安排。保存后调度页定位到对应的计划块。

「甘特图」为规划工作区的同页视图。沿用当前方向，返回列表时保留选择、搜索和排序。目标、阶段和任务从统一表单编辑。已经保存的数值、手动进度及达成字段继续保留。

甘特图行内标出进行中和已完成状态。目标或阶段仅填写开始日期时显示开始节点，填写起止日期时显示日期条。任务在首次有效执行片段的日期显示实际开始，即使尚未排期。实际开始、计划和截止日期独立展示。未记录时间的执行片段和单独的状态变更不会生成时间轴节点。首次打开甘特图或点击「今天」时，将当天定位到可见区。
