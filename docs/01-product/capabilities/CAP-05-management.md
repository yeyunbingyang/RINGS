# CAP-05 管理能力

> 所属层：管理层 Management  
> 优先级：基础生命周期与标签 P0；回顾、统计和高级关联 P1。

## 1. 能力目标

为五层业务体系提供统一的组织、关联、归档、回顾、统计、备份和设置能力。

## 3. Collection 与 Tag

Collection 用于按项目、领域或主题组织对象，可支持层级目录、图标、颜色和排序。Collection 不等于 Direction。

Tag 是跨对象的自定义标记，用于补充领域、来源、主题和其他属性。Candidate 固定分类与 Tag 不同。

工作台的候选事项、目标、阶段、任务、习惯和日历事件共用标签库，可在表单搜索、多选和新建。进入「设置 → 标签管理」可检查各类记录的使用次数、改名、改色或合并。改名和合并同步更新关联记录，包括回收站记录。记录上移除标签只解除当前关联。

## 4. Relation

支持 Candidate、Goal、Stage、Task、Habit、CalendarEvent、Material 等对象之间的关联。关系需要记录来源、目标、关系类型和创建时间。

关系类型示例：来源于、关联、阻塞、支持、引用、后续行动。具体枚举待设计。

## 5. 生命周期管理

- 完成：对象达成完成条件。
- 取消：不再继续执行。
- 归档：退出日常视图，可恢复。
- 删除：移除对象，需有明确安全策略。
- 恢复：从归档或回收机制恢复。

归档不等于删除。取消不等于完成。

## 6. Review（周期回顾）

回顾可以按日、周、月或自定义周期进行。候选事项回顾不要求每日清空。Review 可以沉淀已完成事项、未解决问题、关键 Decision、新 Candidate、新 Task 和下一步行动。

## 7. Statistics（统计）

统计只帮助用户理解工作方式，不直接改变业务状态。

可能的统计维度：
- Task 完成数量与完成周期。
- 计划与实际投入时间。
- WorkSession 时间分布。
- Habit 执行情况。
- Goal / Stage 进度。
- Candidate 转换情况。

指标口径和展示方式需在设计阶段确定。

## 8. Backup / Export

- 首版应提供数据备份与导出。
- 备份需要包含必要的业务数据和附件元数据。
- 外部引用只备份引用信息，不自动复制源文件夹。
- 恢复前应提示覆盖范围。
- 导出格式和备份频率待技术设计确认。

## 9. 验收要点

- [ ] 支持 Collection 和 Tag。
- [ ] 支持跨对象关联。
- [ ] 归档可恢复。
- [ ] 完成、取消、归档、删除语义不同。
- [ ] Review 可以沉淀新的 Candidate / Task / Decision。
- [ ] Statistics 不直接修改业务状态。
- [ ] 支持数据备份和导出。
- [ ] 外部引用不会被误认为已备份其源文件。

## 桌面侧栏

顶部快捷操作在笔记本宽度保留前三项，其余按设置顺序放入「更多」。路径和「新建」保持单行。视口高度较小时，侧栏收紧品牌区和导航间距，给工作区和挂起事项留出更多空间。

侧栏的工作区导航单独滚动。导航下方的「挂起事项」显示挂起卡片数，点击后在侧栏旁打开独立滚动的面板。开发地图、设置、回收站固定在侧栏底部。上下各自沿用导航设置中的相对顺序、名称、图标和可见性，当前页面使用深绿选中态。
