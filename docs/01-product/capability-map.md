# RINGS 能力地图（Capability Map）

> 能力按“用户能够完成什么事情”拆分，不按页面或数据库表拆分。优先级沿用当前 PRD v2.2.2；具体交付顺序见 `04-delivery/`。

## 1. 一级能力

| 一级能力 | 编号 | 所属层 | 核心价值 |
|---|---|---|---|
| 捕捉能力 | CAP-01 | 捕捉层 | 不遗漏信息，澄清候选事项 |
| 规划能力 | CAP-02 | 规划层 | 把长期方向转成目标和阶段 |
| 执行能力 | CAP-03 | 执行层 | 管理已承诺的行动和习惯 |
| 可视化调度能力 | CAP-04 | 可视化调度层 | 把任务安排到时间线上，是默认首页 |
| 管理能力 | CAP-05 | 管理层 | 组织、关联、回顾和维护全局数据 |

## 4. 能力与页面不是一一对应

- 首页可以组合 CAP-04、CAP-03、CAP-02 的摘要和快速创建。
- Candidate 详情页组合 CAP-01 与 XCAP-01。
- Task 详情页组合 CAP-03、CAP-04、XCAP-01、XCAP-02、XCAP-03。
- Goal 详情页组合 CAP-02、CAP-03 和 XCAP-01。
- Review 页面组合 CAP-05 与跨层记录。

## 5. 优先级解释

- P0：当前 PRD 定义的核心基线能力。
- P1：核心闭环后的执行与管理扩展。
- P2：增强能力。
- 待决策：来源于历史需求或当前 PRD 存在范围歧义，冻结前需要确认。

P0 不代表已经开发，也不代表所有 P0 必须在同一个软件版本交付。

本轮首页原型覆盖 CAP-01 快速资料捕捉、CAP-02 Goal / Stage 创建交互、CAP-03 Task / Subtask 编辑、CAP-04 首页工作区与任务池。当前证据级别均为 prototype_only，不改变能力优先级，也不代表正式开发完成。
