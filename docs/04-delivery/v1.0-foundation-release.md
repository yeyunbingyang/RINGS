## 3. 已建立能力

- Task：创建、完成、软删除、恢复。
- Plan：创建、取消、时间冲突检测和用户确认。
- WorkSession：开始、结束、实际投入秒数。
- Web：IndexedDB Repository。
- Desktop：Tauri SQL Plugin + SQLite Repository。
- SQLite：0001_core.sql 初始 migration。
- 双端：同一个 apps/client React SPA。

## 4. 数据规则

- Task / Plan / WorkSession 独立。
- 一个 Task 可以有多个 Plan。
- Deadline 独立于 Plan。
- Plan 取消不删除 Task。
- Task 软删除保留关联计划与执行历史。
- 每个 Task 同时最多一条未结束 WorkSession。
- Plan 冲突提示后由用户决定是否保留，不自动重排。

## 6. 本地验证顺序

1. 安装 Node.js 22.12+、pnpm 10+、Rust 1.90+。
2. 执行 `pnpm install` 并提交生成的 `pnpm-lock.yaml`。
3. 执行 `pnpm typecheck` 和 `pnpm build:web`。
4. 执行 `pnpm dev:web`，验证 IndexedDB 的 Task / Plan / WorkSession。
5. 执行 `pnpm dev:desktop`，验证 SQLite migration 和相同用例。
6. 关闭并重启两端，确认数据可恢复。
7. 通过后再标记 DEV-BASE-01 为 verified。
