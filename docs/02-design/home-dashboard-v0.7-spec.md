## 1. 本轮目标

本轮以可视化调度作为 RINGS 默认首页，优先验证桌面工作台的信息层级、时间安排与任务池的协作方式，并补齐快速捕捉、任务编辑和创建后续安排的操作入口。

## 2. 首页整体布局

### 2.1 固定区域

桌面端采用固定工作区布局，避免页面整体滚动：

- 顶部导航固定，提供全局搜索、快速收藏资料和新建入口。
- 首页标题、快速创建入口、日期信息和摘要卡片固定在调度工作区上方。
- 时间安排面板的标题、日期切换、视图切换和工具区固定。
- 未安排任务池的标题、添加任务入口、搜索和筛选区固定。
- 时间轴内容与任务池列表分别独立滚动；不让整个页面随其中一个区域滚动。

### 2.2 全屏专注

时间安排区域提供全屏专注模式：进入后扩大时间安排可视面积，退出后恢复原有布局，并支持 Escape 键退出。全屏专注只改变视图，不改变 Plan 或 Task 数据语义。

### 2.3 滚动条

时间轴、任务池列表和弹窗内容区采用统一细窄滚动条；轨道尽量透明，滑块使用低对比度中性色和圆角；Hover 时提高滑块对比度。保留原生滚动行为和键盘可访问性，不用隐藏滚动条代替样式优化。

## 3. 未安排任务池

任务池只展示已经确认执行、但尚未安排有效未来 Plan 的 Task。Candidate 和纯资料收藏不进入任务池。

- “添加任务”放在任务池标题栏，不在列表底部重复放置主要新增入口。
- 新建成功后，新任务显示在任务池列表首位。
- 新任务默认保持未安排，除非用户主动选择日期或时间。
- 每张任务卡片提供独立的“编辑”入口，支持名称、Collection、优先级、预计时长、Deadline、子任务列表和上下文备注。
- 编辑入口不能意外触发拖拽或“安排到时间”。保存后同步刷新任务池卡片和已有 Plan 的标题、预计时长及摘要信息。
- 卡片保留“安排到时间”操作，并支持拖动到时间线；编辑和安排是两个独立动作。

## 4. 顶部快速捕捉资料收藏

顶部导航增加“收藏资料”快捷入口。快速收藏字段：

- 资料名称：必填。
- 网页链接 / 文件路径：可选。
- 标签：可选，支持多个标签。
- 上下文备注：可选，用于记录收藏原因、关键内容或后续关注点。

保存为 Candidate，分类为“资料（Resource）”。保留标签、上下文备注和外部引用。仅保存 URL / URI / 路径，不自动读取、复制、上传或扫描外部文件。完整资料管理仍属于 Candidate 管理能力。

## 5. 创建与编辑事项

### 5.1 Candidate

- 捕捉表单支持选择 Candidate 分类。
- 标签类型与自定义 Tag 分开：分类说明事项是什么，Tag 用于补充标记。
- 支持上下文备注和列表式补充资料。
- 补充资料支持名称、链接或文件路径等引用信息。

### 5.2 Task

执行事项只保留普通任务、习惯两种形态。Task 创建表单不再显示倒计时、正计时、计次、不计时等“执行方式”选项。历史执行模式不因原型出现过就自动恢复为当前要求。

习惯的量化目标使用“量词”表达，不使用“计次”作为字段名称，具体单位由用户定义。

Task 支持以列表方式添加、编辑和删除子任务，用于把一个较大的行为拆分为可逐步完成的步骤。子任务不是独立 Candidate。

### 5.3 Goal 与可选 Stage

创建 Goal 时允许可选地同时建立多个子阶段（Stage）。Stage 可以逐条添加、编辑、删除和排序；不建立 Stage 也可以保存 Goal。Stage 属于 Goal 的规划结构，不自动生成 Task；后续可为 Stage 创建或关联 Task。

## 6. 创建后的下一步安排

- 暂不安排：Task 保存到未安排任务池；用户之后可从任务池选择它并确认日期、开始时间和时长。
- 已经安排：保存当前 Plan 后，可以选择继续安排下一项；下一项的建议开始时间接续当前时间块结束时间。
- 接续安排是可选操作，不自动创建额外 Task，也不覆盖已有 Plan。
- 用户可以取消后续安排，回到首页继续处理。

## 7. Calendar Event 时间录入

事件日期和开始时间必填，结束时间允许暂时留空。结束时间尚未确定时，界面应标记“结束待补”，不得把视觉占位时长当作实际结束时间。事件结束后，用户可以从时间轴事件卡片进入补录流程，填写实际结束时间；补录后更新事件实际时长。Calendar Event 与 Task、Deadline、Plan 保持独立语义。

## 8. 弹窗与响应式

- 新建、编辑和快速收藏弹窗限制最大高度，不得超出视口。
- 标题栏和底部操作区固定；仅表单内容区滚动。
- 桌面端使用适合内容的最大宽度。
- 窄屏下弹窗宽度适配视口，操作按钮保持可见。
- 表单字段分组清楚，长内容使用内部滚动，不推动整个页面滚动。

## 10. 已知限制与下一步

当前是前端交互原型，刷新后示例数据和新增数据不会持久保存；未接入正式数据库、Repository、API、身份认证或云同步；未验证生产环境性能、无障碍完整性和跨浏览器兼容性。当前交互测试证据只能标记为 prototype_only。下一阶段优先设计 Candidate Pool / 资料收藏管理、Goal / Stage 详情、Task 详情和数据持久化方案。
