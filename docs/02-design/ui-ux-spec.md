# RINGS UI / UX 设计规范（初稿）

> 状态：交互原则已部分确认；视觉设计系统和具体布局待原型评审。

## 1. 设计目标

- 让用户快速捕捉，不被复杂表单阻断。
- 让“候选 / 规划 / 执行 / 调度”语义清楚。
- 让时间安排可视、可拖放、可撤销。
- 让长期计划与每日执行保持联系，但不强迫全部事项都进入目标体系。
- 支持键盘操作和鼠标操作。
- Desktop 优先考虑宽屏工作台；Web 适配较窄视口。

## 2. 视觉方向

RINGS 品牌意象为“年轮、积累、生长”。可以探索同心环、层叠纹理、柔和自然色系等视觉语言。

尚未确认：最终主色、字体字号、圆角阴影、Logo、深色模式。V2.0 原型的暖色背景和卡片风格可作为历史参考，不是强制设计规范。

## 3. 核心交互原则

1. 快速创建尽量只要求标题。
2. 详情信息分区呈现，避免首屏过长。
3. 状态、分类和时间语义必须可辨识。
4. 拖放提供明确目标区域、悬停反馈和落点预览。
5. 拖放必须提供非拖放替代操作，例如“安排到日期”菜单。
6. 时间冲突不能静默覆盖。
7. 归档、取消、删除必须有不同文案和确认策略。
8. 文件附件与外部引用必须在 UI 上明确区分。
9. 失效路径要保留并提供重新定位。
10. 快捷键不能成为唯一操作方式。

## 5. 状态设计

所有核心组件至少考虑默认、Hover / Focus、Selected、Dragging / Drop Target、Loading、Empty、Error、Disabled 和 Read-only 状态。

## 6. 首页 UI 要求

- 显示当前日期和当前视图。
- 日 / 周 / 月 / 年切换位置稳定。
- 快速创建入口容易发现。
- 时间线是主要视觉区域。
- 未安排任务池可折叠或调整宽度。
- Task 卡片显示标题、预计时长、Deadline、优先级和目标归属（可选）。
- Plan Block 显示计划时段，不把 Deadline 当作执行时间。
- 习惯和日历事件采用可区分的视觉样式。
- 当前时间线有“现在”指示。
- 支持键盘安排任务的替代流程。

## 7. Candidate UI 要求

- 一个统一候选池。
- 十种分类作为筛选条件。
- 显示格式为中文名称（English）。
- 标题优先，备注可展开。
- 补充资料显示文件类型和引用状态。
- 不显示强制清空率。
- 支持批量归档和标签调整。

## 8. 文件与路径 UI 要求

- “上传副本”与“仅保存引用”使用明确文案。
- 本地路径显示为外部引用，不伪装成已上传附件。
- 文件夹引用显示路径和可用状态。
- 失效引用提供“重新定位”。
- 不在没有授权时扫描或上传目录内容。

## 9. 响应式与可访问性

- 桌面端优先使用多栏布局。
- Web 窄屏允许任务池切换为抽屉或独立面板。
- 拖放应提供菜单或键盘替代操作。
- 状态不能只靠颜色表达。
- 交互控件应有可见焦点状态。
- 日期和时间输入应可键盘操作。

## 10. 待原型确认

所有组件尺寸、颜色、间距、字体、动画和断点以 HTML 原型评审结果为准；当前文档不锁定具体像素值。


## 11. 首页原型 v0.7 已确认的交互规范

### 11.1 固定工作区与独立滚动

- 桌面首页整体不随时间轴或任务池内容滚动。
- 顶部导航、首页摘要、时间安排面板头部、任务池头部和任务池搜索筛选区保持固定。
- 时间轴内容和任务池列表分别独立滚动。
- 时间安排面板支持全屏专注模式，支持 Escape 退出。

### 11.2 任务池

- “添加任务”固定在任务池标题栏，不放在列表底部。
- 新建任务置于列表首位。
- 每张任务卡片提供快速编辑入口，编辑字段包含名称、Collection、优先级、预计时长、Deadline、子任务和上下文备注。
- 编辑操作不得触发卡片拖拽或排期。

### 11.3 顶部快速收藏

顶部快捷按钮按用途使用低饱和底色和不同图标。「收藏资料」复用快速捕捉表单，只隐藏分类选择。候选事项固定保存到「资料（Resource）」，标签、备注、清单和文件资料区沿用统一布局。

### 11.4 表单弹窗

- 弹窗最大高度受视口约束。
- 标题栏和底部操作区固定。
- 只有内容区域滚动。
- 桌面和窄屏均不得发生视口外溢。

### 11.5 视觉滚动条

时间轴、任务池和弹窗使用统一细窄滚动条；默认低对比度，Hover 时增强可见性。不得为了视觉简洁而破坏滚动可发现性。


## 12. 执行库统一页面规范

### 12.1 页面入口与视图

- 侧边栏只保留一个“执行库”入口，不再单独显示“任务库”和“习惯”。
- 页面内提供“全部执行 / 普通任务 / 习惯”三种视图。
- 全部执行汇总展示 Task 与 Habit 摘要，但每张卡片必须标注对象类型。
- 普通任务筛选：全部、未安排、已安排、进行中、等待 / 阻塞、已完成、已归档。
- 习惯筛选：今日、本周、全部习惯、暂停中。

### 12.2 普通任务

- 卡片显示标题、状态、优先级、预计时长、Deadline、子任务进度和调度摘要。
- 新建任务只要求标题；默认创建未安排 Task。
- 可选填写说明、Collection、Tag、优先级、预计时长、Deadline、子任务、Goal / Stage 关联和上下文备注。
- 不出现“执行方式”字段。
- 子任务以可编辑列表呈现；创建和编辑不要求用户先确定排期。

### 12.3 习惯

- 卡片显示名称、重复规则、量词目标、今日 / 本周状态和最近执行记录。
- 新建习惯要求名称与重复规则；量词由数值和单位组成。
- Habit 规则与 HabitOccurrence 单次执行实例分开呈现。
- 记录执行作用于 HabitOccurrence，不修改 Habit 规则。
- 习惯不使用普通任务的“未安排”筛选；需要安排时间时，安排某次 HabitOccurrence。

### 12.4 与调度层的边界

- 首页未安排任务池只接收正式 Task，不接收 Habit 规则和 Candidate。
- Task 拖放只创建或更新 Plan，不创建重复 Task，也不自动修改 Deadline。
- HabitOccurrence 可以进入调度流程；Habit 规则本身不作为普通任务排期。
- Plan 取消不会删除 Task 或 HabitOccurrence。

页面详细规格见 execution-library-v0.1-spec.md。


## 13. 执行库 v0.2 编辑交互

- 普通任务详情的“编辑”必须打开真实编辑表单，不得使用仅显示 Toast 的占位操作。
- 编辑字段：名称、说明、优先级、预计时长、Deadline、Collection、子任务。
- 习惯详情提供“编辑规则”，字段为名称、说明、重复规则、量词数值和单位。
- 编辑共用创建表单，但必须锁定当前对象类型，不能将 Task 直接变成 Habit 或反向转换。
- 编辑保存不得重置 Task 状态、已完成子任务计数或 Habit 今日执行状态。
- 量词数值和单位必须同时填写或同时留空。
- 当前 v0.2 仅为内存原型；数据持久化与按日期的 HabitOccurrence 历史尚未实现。


## 14. 规划工作区 v0.8

- 桌面采用 Direction 左栏、Goal 列表中栏、Goal 详情右栏。
- Direction 可独立存在；选择方向后过滤 Goal。
- Goal 列表显示方向、生命周期、期限、目标进度、Stage 数和关联 Task 数。
- Goal 详情分区显示指标、完成条件、Stage 和 Task 关联。
- 创建 Goal 时 Stage 为可选列表；每行阶段可单独输入名称、说明、期限和完成条件。
- Stage 支持编辑、排序、状态更新和删除；删除 Stage 不删除 Task。
- Goal 进度和 Task 完成率必须分开显示，不能以任务完成率冒充目标进度。
- Goal 创建 Task 默认未安排，不在规划页面创建 Plan。
- 窄屏下三栏纵向堆叠；弹窗标题和操作区固定，内容区内部滚动。
- 规划工作区详细规格见 planning-workspace-v0.8-spec.md。

## 工作台设置

侧栏通过「设置」进入工作台设置。导航与快捷操作的配置入口位于设置页内，顶部配置按钮也可以进入设置。

设置顶部有「工作区与偏好」「导航与快捷操作」「数据与恢复」三个页签。工作区与偏好包含名称、调度和界面显示，导航页保留左右入口的配置和保存，数据页集中备份恢复及回收站。顶部配置按钮直达顶部快捷按钮配置。走查时切换页签、核对草稿保留与分组保存，并重新载入检查设置。

每周起始日、默认任务时长、列表密度和任务统计角标采用可直接点击的分段单选。点击「保存工作区偏好」后，核对周月视图、任务表单和侧栏角标。

## 回收站

从侧栏「回收站」进入独立管理页。「数据与恢复」和甘特图中的入口也打开同一页面。可按记录类型和名称筛选，列表显示名称、类型和删除时间。走查时先取消一次永久删除，再核对恢复、确认永久删除和刷新后的结果。

## 候选分类与指标卡片

业务标签在列表、详情、筛选和编辑表单中使用统一的低饱和色系。同名标签同色。未选的常用标签使用白底，已选标签显示对应浅色和移除标记。走查时为候选事项添加多个标签，保存后比较列表、详情、筛选和编辑显示。

候选事项分类和规划、执行管理的指标卡按含义使用低饱和底色。分类选中态使用描边和加粗，指标卡保留名称、数值、说明和标题前的色点。计划超时有记录时用琥珀色提醒，零记录用中性色。走查时切换候选分类，核对选中样式、列表结果和指标数值。
