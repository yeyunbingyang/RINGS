# RINGS 执行库页面设计规格 v0.1

> 日期：2026-11-18  
> 状态：页面结构与交互方案首版；等待原型评审。  
> 能力映射：CAP-03、CAP-04、CAP-05。  
> 领域边界：Task、Habit、HabitOccurrence 仍是不同实体；本规格只合并页面入口与管理体验。

## 1. 页面目标

将原“任务库”和“习惯”合并为统一的“执行库（Execution Library）”，让用户在同一工作区管理所有已经确认要持续执行的事项，同时避免把习惯规则误当作普通任务。

页面回答三个问题：
1. 我已经承诺要做什么？
2. 哪些任务尚未安排、正在进行或等待处理？
3. 哪些习惯今天 / 本周需要执行，执行记录如何？

## 2. 页面信息架构

### 2.1 一级入口

侧边栏只保留一个入口：**执行库**。不再单独出现“任务库”和“习惯”两个一级页面。

### 2.2 页面内主视图

顶部使用三段式对象视图：

| 视图 | 内容 | 默认排序 |
|---|---|---|
| 全部执行 | 普通任务 + 习惯摘要 | 最近更新优先；今日待执行可置顶 |
| 普通任务 | Task / Subtask | 未完成优先，其次优先级、Deadline |
| 习惯 | Habit 规则 + 今日 HabitOccurrence | 今日待执行优先，其次用户排序 |

对象视图是同一页面中的筛选，不创建两套数据，也不改变对象类型。

### 2.3 普通任务筛选

- 全部
- 未安排
- 已安排
- 进行中
- 等待 / 阻塞
- 已完成
- 已归档

“未安排”只筛选没有有效未来 Plan 的 Task，不包含 Habit 规则或 Candidate。

### 2.4 习惯筛选

- 今日
- 本周
- 全部习惯
- 暂停中
- 已归档

习惯规则与单次执行实例分层展示。今日列表展示 HabitOccurrence 的状态和快捷记录入口；不将 Habit 本身当作一个待排期任务。

## 3. 桌面布局

建议采用三栏工作台：

- **左侧筛选栏（约 210–230px）**：对象视图、状态筛选、Collection、Tag。
- **中间列表区（弹性宽度）**：搜索、排序、批量操作、任务 / 习惯卡片。
- **右侧详情区（约 340–390px）**：选中对象的详情与相关记录；窄屏时改为侧滑抽屉。

页面标题区固定显示：
- 标题“执行库”及说明。
- 统计摘要：待安排任务、进行中任务、今日习惯待执行、本周完成。
- “新建执行事项”主按钮。
- 搜索框和视图切换。

列表内容区独立滚动；页面标题、筛选工具栏和详情区头部不随列表滚动。

## 4. 统一卡片与差异信息

### 4.1 普通任务卡片

必须展示：
- 标题。
- 类型标记“普通任务”。
- 生命周期状态。
- 优先级。
- 预计时长（若有）。
- Deadline（若有）。
- 子任务进度（若有）。
- 调度摘要：未安排 / 下一次 Plan 时间。
- Collection / Tag（可选）。

快捷操作：
- 完成 / 重新打开。
- 编辑。
- 安排时间（打开日期与时间选择器；也可从首页任务池拖放）。
- 更多：等待、阻塞、取消、归档。

编辑支持标题、Collection、优先级、预计时长、Deadline、子任务列表、上下文备注。创建表单不出现“执行方式”选项。

### 4.2 习惯卡片

必须展示：
- 习惯名称。
- 类型标记“习惯”。
- 重复规则摘要（例如：每天、每周一三五）。
- 量化目标：以“量词”展示数值与单位（例如 30 分钟、20 页、2 公里）。
- 今日 / 本周执行状态。
- 最近执行记录摘要。

快捷操作：
- 记录本次执行 / 更新量词结果。
- 查看执行历史。
- 编辑习惯规则。
- 暂停 / 恢复。
- 归档。

习惯不提供普通任务的 Deadline / 未安排状态筛选；若某次 HabitOccurrence 需要时间安排，由调度层安排该次实例。

## 5. 新建与编辑流程

点击“新建执行事项”后，先选择对象类型：
- 普通任务
- 习惯

### 普通任务表单

必填：标题。  
可选：描述、Collection、Tag、优先级、预计时长、Deadline、父任务 / 子任务、关联 Goal / Stage、上下文备注。

保存后默认创建为未安排 Task；用户主动选择日期 / 时间时才创建 Plan。

### 习惯表单

必填：名称、重复规则。  
可选：开始日期、结束日期、量词目标（数值 + 单位）、提醒时间、Collection、Tag、关联 Goal / Stage、说明。

重复规则至少预留：
- 每天
- 每周指定星期
- 每月指定日期
- 自定义间隔（后续增强）

本轮原型只验证基础每日 / 每周交互；HabitOccurrence 自动生成策略仍待领域决策，不在原型中暗示已经实现完整调度引擎。

## 6. 详情面板

### Task 详情
1. 基本信息与生命周期状态。
2. 子任务列表。
3. Deadline / Plan 摘要（明确区分）。
4. WorkSession 实际投入记录。
5. Thought Stream（备注、问题、决策、结论、下一步）。
6. WorkContext（网页、Repo、文件 / 文件夹、AI 会话等）。
7. 补充资料与关联对象。

### Habit 详情
1. 习惯目标与重复规则。
2. 量词目标与单位。
3. 今日 / 本周执行实例。
4. 执行历史与连续记录（统计口径待确定）。
5. 提醒与暂停设置。
6. 关联 Goal / Stage、Collection、Tag。

## 7. 与首页调度的关系

- 首页未安排任务池只接收正式 Task，不接收 Habit 规则。
- HabitOccurrence 是某一次习惯实例，可在调度层显示或安排。
- 从执行库点击“安排时间”时，普通任务创建 / 更新 Plan；习惯必须先选择某次 HabitOccurrence。
- Task 拖放只创建或更新 Plan，不创建重复 Task，不自动修改 Deadline。
- Plan 取消不会删除 Task 或 HabitOccurrence。

## 8. 生命周期与操作文案

Task：准备就绪、进行中、等待、阻塞、已完成、已取消、已归档。  
Habit：启用、暂停、已归档。  
HabitOccurrence：待执行、已完成、跳过、未完成（最终枚举待领域设计）。

“完成、取消、归档、删除”不得混用；归档可恢复。

## 9. 响应式

- 桌面端：三栏布局。
- 平板：左侧筛选可折叠，详情面板按需打开。
- 手机：顶部对象视图切换；筛选进入抽屉；列表单列；详情独立页面 / 抽屉。
- 所有拖放操作必须提供“安排到日期”菜单替代方案。

## 10. 原型验收清单

- [ ] 侧边栏只有一个“执行库”入口。
- [ ] 页面内可切换全部执行 / 普通任务 / 习惯。
- [ ] 普通任务与习惯卡片明确标注类型和差异字段。
- [ ] 未安排筛选不包含 Habit 规则。
- [ ] 新建任务默认未安排。
- [ ] 新建习惯使用重复规则和“量词”，不出现“计次”或“执行方式”字段。
- [ ] Habit 快捷记录作用于 HabitOccurrence，不改变 Habit 规则本身。
- [ ] Task 详情显示 Subtask、Plan、WorkSession、Thought、WorkContext 入口。
- [ ] Habit 详情显示规则、量词和执行历史。
- [ ] 窄屏布局无横向溢出。

## 11. 未决策事项

- HabitOccurrence 的预生成窗口与生成时机。
- 每周次数目标与指定星期规则如何同时表达。
- 补打卡、跳过、未完成的状态与统计口径。
- 习惯连续记录是否纳入首版。
- HabitOccurrence 是否支持多个 Plan / WorkSession 的约束。
