# RINGS 用户交互流程

## FLOW-01 快速捕捉候选事项

```text
用户触发全局快速捕捉
    ↓
输入标题 / 粘贴内容
    ↓
保存为 Candidate
    ↓
可选补充分类、备注、标签、资料和时间
    ↓
留在当前页面，不强制跳转
```

## FLOW-02 Candidate 回顾与转换

```text
打开候选事项池
    ↓
选择一条 Candidate
    ↓
判断后续去向
    ├── 保留 / 孵化
    ├── 归档 / 取消
    ├── 关联已有对象
    ├── 转为 Task
    ├── 转为 Direction / Goal
    └── 转为 CalendarEvent
```

转换必须保留来源 Candidate 和必要内容。

## FLOW-03 首页快速创建 Task

```text
首页点击“新建任务”
    ↓
输入标题
    ↓
选择仅创建或立即安排
    ├── 仅创建 → Task 进入未安排任务池
    └── 立即安排 → 选择日期 / 时间段 → 创建 Task + Plan
```

## FLOW-04 未安排 Task 拖放到时间线

```text
未安排任务池选择 Task
    ↓
拖到某日或某时间段
    ↓
创建 / 更新 Plan
    ↓
检查冲突
    ├── 无冲突 → 保存
    └── 有冲突 → 提示用户选择
    ↓
时间线更新
```

拖放不创建重复 Task，不自动改变 Deadline。

## FLOW-05 开始执行

```text
点击时间线中的 Task
    ↓
查看任务详情
    ↓
开始 WorkSession
    ↓
暂停 / 继续 / 结束
    ↓
记录实际投入和结果
    ↓
更新 Task 状态和统计
```

## FLOW-06 Goal / Stage 创建任务

```text
打开 Goal
    ↓
选择 Stage 或直接关联 Goal
    ↓
创建 Task
    ↓
Task 进入执行层
    ↓
Task 可在首页安排 Plan
```

## FLOW-07 文件夹引用

```text
在 Candidate / Task 详情中添加资料
    ↓
选择“引用文件夹”
    ↓
Desktop 文件夹选择器
    ↓
保存路径和显示名称
    ↓
展示引用状态
    ↓
点击打开 / 检查路径 / 重新定位
```

Web 不承诺直接访问本地任意路径。

## FLOW-08 等待事项跟进

```text
Candidate（等待）或 Task（waiting）
    ↓
设置 follow_up_at
    ↓
到期提醒
    ↓
记录回复或检查结果
    ├── 解除等待
    ├── 创建后续 Task
    └── 继续等待并更新跟进时间
```

## FLOW-09 周 / 月 / 年计划细化

```text
年度 Direction / Goal / Stage
    ↓
月度重点和阶段节点
    ↓
周计划分配日期
    ↓
日计划安排时间块
    ↓
实际执行与回顾
```

用户可以从任意时间尺度开始，不强制先有年度计划。


## FLOW-10 顶部快速收藏资料

用户点击顶部“收藏资料”
    ↓
填写资料名称（必填）
    ↓
在快速捕捉表单中可选添加标签、备注、清单和资料
    ↓
保存为 Candidate，分类为“资料（Resource）”
    ↓
按捕捉流程刷新候选事项并显示保存反馈

从「收藏资料」进入时隐藏分类选择。验收时选择文件、拖入文件或粘贴链接，保存后在「资料」分类的候选事项详情核对文件与引用。外部链接或路径只保存引用。

## FLOW-11 任务池快速编辑

用户在任务池任务卡片点击“编辑”
    ↓
打开快速编辑弹窗
    ↓
修改名称、Collection、优先级、预计时长、Deadline
    ↓
可选编辑子任务列表和上下文备注
    ↓
保存并刷新任务池卡片及关联 Plan 摘要

编辑按钮与拖拽、安排操作互相独立。

## FLOW-12 Task 创建后的下一步

创建 Task 并保存
    ↓
判断 Task 是否已有 Plan
    ├── 暂不安排 → Task 进入未安排任务池 → 用户之后选择 Task 并确认日期 / 时间
    └── 已经安排 → 保存当前 Plan → 可选继续安排下一项 → 默认建议从当前时间块结束时间接续 → 用户确认后保存下一项 Plan

## FLOW-13 Goal 与可选 Stage

创建 Goal → 填写基本信息 → 可选添加多个 Stage → 编辑、删除或排序 → 保存 Goal。

未添加 Stage 不阻止 Goal 保存；Stage 不自动转为 Task。

## FLOW-14 Calendar Event 结束时间补录

创建 Calendar Event → 填写事件日期和开始时间 → 结束时间可留空 → 保存并标记“结束待补” → 事件结束后从事件卡片补录实际结束时间 → 更新事件实际时长。

未补录前不得将视觉占位时长视为真实结束时间。


## FLOW-15 执行库统一入口与对象视图

从主导航进入「执行管理」，核对宽屏下五张统计卡片位于标题与「添加执行事项」之间。缩窄窗口后，卡片换到下方，仍位于筛选栏上方。

用户打开“执行库” → 选择“全部执行 / 普通任务 / 习惯”：
- 普通任务视图：按未安排、已安排、进行中、等待 / 阻塞、已完成筛选 Task。
- 习惯视图：按今日、本周、全部习惯、暂停中筛选 Habit。
- 全部执行视图汇总展示 Task 与 Habit 摘要，但卡片必须保留对象类型标识。

页面入口合并，不合并 Task 与 Habit 的领域实体，也不将 Habit 规则转换为普通 Task。

## FLOW-16 新建普通任务

用户点击“新建执行事项” → 选择“普通任务” → 输入标题（必填）→ 可选填写说明、Collection、Tag、优先级、预计时长、Deadline、父子任务、Goal / Stage 关联和上下文备注 → 保存为 Task。

默认不创建 Plan；用户主动安排时间后才进入首页时间线。表单不提供“执行方式”选项。子任务可按列表添加、编辑和排序。

## FLOW-17 新建习惯与记录执行

用户点击“新建执行事项” → 选择“习惯” → 输入名称和重复规则 → 可选设置开始日期、量词目标（数值 + 单位）、提醒、Collection、Tag 和说明 → 保存 Habit 规则。

在今日 / 本周视图中选择某次 HabitOccurrence → 记录完成、跳过或更新量词结果。记录作用于单次实例，不修改 Habit 重复规则。

HabitOccurrence 的预生成策略、补记录规则和统计口径仍待领域决策。

## FLOW-18 Candidate 回顾与分流

打开 Candidate 详情 → 查看分类、状态、备注、补充资料和时间信息 → 选择保留、孵化、关联、转换、归档或取消。

转换前选择 Task / Goal / CalendarEvent，预览字段映射并由用户确认。转换成功后保留原 Candidate、备注、标签、附件和外部引用，并建立来源关系。

## FLOW-19 Candidate 转为 Task

Candidate 详情 → 点击“转为 Task” → 预填标题、描述和标签 → 用户确认并补充 Task 字段 → 创建正式 Task → Candidate 标记为 converted → Task 进入执行库的普通任务视图。

新 Task 默认未安排；之后由用户创建 Plan。Candidate 不因存在 Deadline Hint 而自动转换或自动排期。


## FLOW-20 编辑普通任务

执行库选择普通任务 → 打开详情 → 点击“编辑” → 在编辑表单中修改标题、说明、优先级、预计时长、Deadline、Collection 和子任务 → 保存 → 更新原 Task。

编辑不得自动创建 Plan，不得重置 Task 状态或已完成子任务计数。

## FLOW-21 编辑习惯规则

执行库选择习惯 → 打开详情 → 点击“编辑规则” → 修改名称、说明、重复规则和量词目标 → 保存 → 更新原 Habit 规则。

编辑规则不修改既有 HabitOccurrence 记录；量词数值与单位必须同时填写或同时留空。


## FLOW-22 创建 Direction 与 Goal

打开规划工作区
    ↓
可选创建 Direction（方向可以独立存在）
    ↓
创建 Goal
    ↓
填写名称、说明、衡量方式、期限和完成条件
    ↓
可选添加多个 Stage
    ↓
保存 Goal
    ↓
不自动生成 Task 或 Plan

## FLOW-23 Goal / Stage 关联执行任务

打开 Goal 详情
    ↓
选择创建 Task 或关联已有 Task
    ↓
选择直接关联 Goal，或指定一个 Stage
    ↓
保存关联
    ↓
Task 仍由执行库管理
    ↓
新建 Task 默认进入未安排任务池，由调度首页创建 Plan

解除关联只移除 Goal / Stage 关系，不删除 Task。

## FLOW-24 Goal 指标更新与完成确认

Goal 详情
    ↓
根据指标类型更新数值 / 里程碑 / 布尔结果 / 自定义进度
    ↓
单独查看关联 Task 完成率
    ↓
用户判断目标是否达成
    ↓
明确标记 Goal 完成

Stage 全部完成不自动将 Goal 标记为完成；Task 完成率不直接作为 Goal 进度。

## 共用清单编辑（桌面端）

1. 从快速捕捉或收藏资料打开新表单，切换到「基础信息」填写标签、备注和来源，再切换到「清单」。
2. 在左侧点「快速新建清单」，右侧可填多行说明、添加文件，或逐行添加网址和路径。可在同一条目中组合三类内容，已有条目在左侧切换，未保存的输入随表单保留。
3. 点「完成条目」可回到左侧继续选条目。用表单底部的按钮保存记录。双击已保存的候选事项，按相同操作编辑多行说明、移动资料或下载附件。
4. 点击文件名旁的图片缩略图查看大图。按 Esc 或点击「关闭」回到原条目，保留表单草稿。在只读详情中展开清单，也可用同样方式预览。

## 表单固定选项与统一标签

1. 在规划中打开新建目标或双击已有目标。类型、优先级和状态优先同排，紧接其下选择标签，再填写所属方向、日期和子阶段。
2. 打开表单即可点击已有标签，选中的快捷标签带勾，再点一次可取消。超过 6 个标签时，使用「搜索或新建标签」查找其余标签，结果支持方向键和回车。表单也可暂存新标签，保存记录后加入工作台标签库。目标、候选事项、任务、习惯、阶段和日历事件共用此选择器。
3. 从表单或「设置 → 标签管理」打开标签库，搜索标签并核对使用次数。编辑名称或颜色后保存，合并时选择已有目标标签并确认。从表单打开的标签管理关闭后，返回原表单并保留草稿。
4. 目标、阶段、任务、习惯和日历事件沿用同一组件。阶段完成条件、任务子任务和习惯字段继续在各自的基础信息中管理。

## 规划排序与从阶段建任务

在规划页选择「手动顺序」，拖动目标或阶段左侧的手柄，也可以键盘聚焦手柄后按上、下方向键。切换「优先级」查看高、中、低，同级保持手动位置。筛选时只调整当前可见条目的位置。目标和阶段的属性表单里可以修改优先级。点击阶段行或阶段详情的「新建任务」，核对自动带入的目标和阶段后提交。

## 目标分类

新建或编辑目标时选择「成果目标」或「持续目标」。表单桌面布局将上下文、完成条件和子阶段放在同一横向区域；窗口变窄时自动分列。成果目标可以填写完成条件；详情显示完成条件与阶段进度。持续目标显示当前阶段、累计完成和待推进阶段数。当前阶段全部完成后，可以直接追加下一阶段。规划列表可以按目标类型筛选；甘特图和复盘也按对应方式显示阶段数据。只填写开始日期时，甘特图显示可点击的「开始」节点；从未排期区拖入持续目标时只设置开始日期。

## 目标详情

桌面规划列表在顶部横排方向筛选，下方并列目标列表与目标详情。右栏超出可用高度时独立滚动，顶部方向与目标列表保留位置。选择其他目标时，详情从顶部显示。近期无安排时只在列表标题显示状态提示。

编辑和更多操作在右栏标题旁，完成、归档和删除从更多操作进入。阶段和任务区各自保留新建入口。无阶段时显示空状态，有阶段时显示推进情况，至少两条阶段时提供排序及拖动手柄。已填写的完成条件直接展示，未填写的备注、完成条件和日期合并到一个可展开区。
## 统一规划工作区

1. 从主导航进入「规划」。核对桌面宽度下四张统计卡片在标题与「新建目标」之间，缩窄窗口后卡片仍完整显示在视图切换栏上方。在规划页头的「发展方向」区域选择方向或「未归属方向」，在左侧筛选目标，右侧查看阶段与任务。方向选项总数达 7 项时，核对搜索与选中状态。
2. 点方向区的「＋ 新建方向」。选中方向后，可编辑该方向、用「新建目标」自动带入方向，或用「关联已有目标」从未归属和其他方向中选择目标。选择已归属的目标时，确认前显示将移出的方向。也可在目标编辑页重新选择或清除归属。
3. 在阶段行或详情点击「新建任务」，核对预填目标和阶段后保存。任务先进入执行管理的未安排任务池。
切换目标后核对「已选」标记和右侧标题。阶段逐行展示，任务和子任务在各自阶段内直接显示。任务可勾选完成或恢复，阶段可直接新增、关联、移出任务或挂起。点阶段名称展开说明，双击仍可编辑。

在任务行点「编辑」或双击名称，直接打开任务表单。在子任务行做同样的操作，检查光标定位到该子任务名称。点击父任务行的「＋ 子任务」，输入名称后按回车或点击「添加」。新条目立即显示在父任务下。按 Esc 可关闭输入框。

打开「未归属与习惯」，核对已关联目标的任务只在所属目标或阶段展示。未归属任务可从编辑表单选择目标和阶段。打开已归属任务的详情可查看执行记录，点击「返回所属目标」回到对应目标。

4. 点击上方「甘特图」，查看同方向的规划时间轴。拖动日期条或进度条边缘调整日期，双击目标、阶段或任务名称所在行打开已有编辑表单。返回列表保留筛选和排序。
5. 确认进行中或已完成的事项状态在行名下方可见。仅设置开始日期的目标与阶段显示开始节点。任务已有执行时间时，点击「实际开始」可回到任务编辑，悬停可查看日期和时刻。点击「今天」可将当天滚入可见区。
6. 返回列表。未来 7 天无安排时，核对列表标题旁的提示。有安排时，在列表下方双击安排进入编辑。

## 从侧栏挂起阶段快速新增任务

在规划的阶段卡片点击「挂起」，然后点左侧「挂起事项」进入独立页面。侧栏数量表示挂起卡片数。关联任务和子任务默认收起，每次展开一个卡片。展开阶段后可输入名称，新增关联的未安排任务。单独挂起任务或子任务时，卡片显示已有归属。勾选完成后从页面隐藏，在原列表恢复为待办后可重新显示。点名称可打开详情。

挂起阶段卡单独显示阶段名称、方向和目标。点击关联任务旁的「＋」或单独挂起的父任务卡上的「＋ 子任务」，在原地输入名称并按回车。新条目出现在该父任务下，输入框可继续添加。按 Esc 收起。

从调度首页进入「挂起事项」，确认主区切换到独立页面，侧栏入口高亮。展开一个卡片后再展开另一个，确认前一个收起。

## 从阶段或任务池快速调度

在规划的任务或子任务行点「开始」。调度页显示实际开始时间和执行块，原任务显示为进行中。有其他任务在执行时，先选择并行或中断再开始。已开始的事项可点「看调度」，已中断的事项可点「继续」。

在同一行点「排期」。确认预填的日期、开始时间和时长后，调度页定位到该计划块。已有尚未结束的排期时打开原安排，取消则留在规划页。

日视图每格 15 分钟。指向空白格可预览时段，点击或拖入任务按该格起点排期。

在规划阶段新建任务后点「保存并立即开始」，或从任务池点「立即开始」。如果已有任务在执行，选择「并行开始」或「暂停当前并开始」。调度右侧显示选中任务的开始时间，点击其他执行项或时间轴上的实际时间块可以切换。用「完成并结束」记录结束并完成任务；用「中断」关闭当前片段并保留未完成状态。在执行管理中选择「已中断」，继续同一任务，核对执行记录保留旧片段并新增一段。已结束片段的颜色高度与时间刻度对齐，短片段可点色块下的文字查看详情。

## 子任务安排与执行

在执行管理打开父任务，在子任务行选择「单独排期」或「立即开始」。对已排期的子任务可点「调整排期」，也可在调度时间轴双击对应计划块。实际开始后可在首页右侧或父任务详情逐项暂停、完成。刷新后可从同一子任务继续结束。改名时保留既有排期和执行记录。

## 取消执行任务

在执行管理用任务标题旁的颜色、图标和文字识别状态。打开要取消的任务，在详情点击「取消任务」并确认。核对红色「已取消」标签、已保留的执行记录、以及调度页移除的未完成排期。用「已取消」筛选找到该任务，点击「重新激活」，核对状态恢复为未开始，并检查本次取消的排期已恢复。

## 桌面侧栏导航

用 1130 × 560 CSS 像素的浏览器视口打开执行规划。检查路径和「新建」保持单行，三项快捷操作直接可见，从「更多」仍可打开其余入口。规划标题、四张指标与视图操作同排，目标列表和详情分别滚动。

滚动侧栏工作区和独立挂起页面，核对开发地图、设置和回收站仍固定在底部。点击底部入口后，高亮跟随打开的页面。通过「设置 → 导航与快捷操作」调整显示、名称、图标和顺序，保存及刷新后核对各区域内的顺序。

## 桌面滚动与长弹窗

主工作区、任务池及甘特图共用圆角滚动条样式。长编辑弹窗采用宽版布局，只滚动正文，标题和底部操作始终可用。有溢出时显示浮动滑块，可使用滚轮、拖动或键盘；正文能完整显示时滑块自动隐藏。

## 执行管理与独立甘特图走查

1. 打开「任务管理」，确认默认显示全部，在各分支末尾核对「已完成」组默认收起，展开后核对浅绿色任务行及原有层级。展开或折叠目标、阶段及父任务，核对树表层级及时间列。搜索折叠分支中的任务，确认命中路径自动展开，再清除搜索恢复原折叠状态。点击任务打开右侧详情，关闭后返回原任务行。切换「未完成」「已完成」，再按归属及标签筛选。仅子任务命中时保留父任务上下文。返回「执行规划」，确认其默认仍显示未完成任务。
2. 打开父任务或子任务详情，查看实际开始、结束、执行片段和耗时。对无执行记录的任务标记完成，核对实际时间显示未记录，再恢复未完成。
3. 拖动目标、阶段或同组任务，核对排序切换为手动并在刷新后保留。切回自动排序，核对同优先级项目的开始时间顺序。
4. 删除单个子任务，先尝试在父任务缺失时恢复，再恢复父任务与子任务。核对排期及执行历史。打开「甘特图」移动排期，返回调度首页核对原排期时分和时长。

## 定时复盘走查

1. 在复盘页展开「设置日、周、月复盘时间」，分别启用并保存触发时间。核对到点后调度首页出现 15 分钟排期，刷新后同周期只有一项。
2. 开始定时复盘，核对周期选择和倒计时。暂停、继续并刷新，确认重新打开后使用已记录的剩余时间。
3. 倒计时结束后，检查执行片段已结束。填写并提交，核对历史复盘、任务与排期的完成状态。
