# RINGS v0.3.1｜资料附件、Work Context 与专注页规格

> 状态：HTML 原型增量已完成 Chromium 冒烟验收（prototype_only）。

## 1. Candidate 资料附件列表

Candidate 详情提供列表式资料区，支持：
- 拖放文件进入资料区。
- 在页面聚焦时粘贴剪贴板图片 / 文件。
- 点击选择文件，可多选。
- 每项显示文件名、类型、大小。
- 支持打开 / 下载、上移、下移、移除。
- 文件添加后与 Candidate 绑定，Candidate 转换时来源 Candidate 与附件关系继续保留。

本机服务模式下文件大小不设上限：文件以原始字节流式写入 `data/attachments/`，工作台 JSON 仅保存 `attachmentId`、名称、大小和 MIME 类型。纯浏览器（`file://`）原型模式仍使用 Data URL + localStorage，受浏览器配额限制；大附件请使用本机服务。正式应用若需跨设备同步，仍需在此受控附件服务之上补充内容哈希、来源、权限和校验状态。

## 2. Task Work Context

Task 详情可关联：
- AI 会话
- 本地文件 / 文件夹
- GitHub Repo
- 网页
- 其他自定义引用

每个上下文包含类型、显示名称和 URI / 路径。默认只保存引用，不自动读取、复制、移动或上传源文件。上下文用于恢复任务执行现场。

## 3. 专注页

从 Task 详情进入独立专注页：
- 显示当前 Task 名称和经过时间。
- 可记录 Thought / 工作进展。
- 可返回任务工作区。
- 结束专注时记录 WorkSession 摘要并保留实际投入时间。
- 结束专注不自动将 Task 标记为完成。
- 后续正式实现需支持暂停、继续、异常退出恢复和时间戳校准。
