## 用户复测建议

1. 新建 Direction，并在不创建 Goal 的情况下保存。
2. 创建一个 Goal，不添加 Stage，确认可正常保存。
3. 创建一个 Goal 并添加多个 Stage，调整顺序并标记其中一个完成。
4. 切换数值 / 里程碑 / 布尔 / 自定义进度，检查 Goal 进度口径。
5. 从 Goal 创建 Task，再关联已有 Task，分别检查直接关联与 Stage 关联。
6. 删除 Goal，确认 Task 不被删除；恢复 Goal 后检查关联关系是否还原。
7. 在 1440px 桌面和 390px 窄屏检查列表、详情和弹窗滚动。
