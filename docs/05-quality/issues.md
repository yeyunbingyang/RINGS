# RINGS 待处理问题与风险

> 初始清单来自当前 PRD 的待确认项、能力拆分中的范围歧义，以及原型基线核对。

## 1. 产品范围问题

| ID | 问题 | 当前建议 | 优先级 |
|---|---|---|---|
| OPEN-01 | Candidate 十种分类是否允许多选？ | 一个主要分类 + 多个 Tag | 高 |
| OPEN-02 | Memo / Resource 是否需要独立知识库页？ | 首版统一 Candidate，以筛选视图呈现 | 中 |
| OPEN-03 | Goal 指标类型有哪些？ | 数值、里程碑、布尔、自定义 | 高 |
| OPEN-04 | Task 是否允许关联多个 Stage？ | 一个主要 Stage，其他关系用 Relation | 中 |
| OPEN-05 | Habit 是否支持每周次数目标？ | 建议支持，需评审 | 中 |
| OPEN-06 | HabitOccurrence 是否预生成？ | 建议按需生成 | 中 |
| OPEN-07 | WorkSession 是否允许无 Task？ | 首版先关联 Task / HabitOccurrence | 中 |
| OPEN-08 | 外部日历同步是否进入首版？ | 当前不纳入 | 低 |
| OPEN-09 | 是否支持多设备同步？ | 当前不作为基线 | 中 |
| OPEN-10 | Candidate 回顾提醒频率？ | 用户可配置，默认不强制每日 | 中 |
| OPEN-11 | Gantt 是否独立一级页面？ | 首版作为 Goal / Stage 视图 | 低 |

## 2. 当前 PRD 内部范围一致性问题

| ID | 问题 | 影响 |
