# RINGS v1.0 技术架构冻结记录

> 决策日期：2026-11-20  
> 状态：**已冻结（Accepted）**  
> 平台范围：Desktop + Web 同时开发  
> 实施分支：`feat/v1.0-desktop-web-foundation`

## 1. 用户确认

用户明确选择：**B. Desktop + Web 同时开发**。

该选择表示两个平台同时纳入 v1.0 开发与验收，不代表本版本提供实时跨设备数据同步。云同步继续遵循 ADR-005，不作为 v1.0 前置条件。

## 2. 冻结技术栈

| 领域 | 冻结选择 | 版本基线 |
|---|---|---|
| UI | React | 19.3.1 |
| 语言 | TypeScript | 5.9.3 |
| 构建 | Vite | 8.3.x |
| 包管理 | pnpm Workspace | pnpm 10.x |
| 桌面容器 | Tauri | 2.12.x |
| Rust | stable | 1.90+ |
| Desktop DB | SQLite | Tauri SQL Plugin 2.6.x |
| Web DB | IndexedDB | 浏览器原生 |
| 应用架构 | Domain + Application + Repository Adapter | 共用业务层 |

Node.js 最低要求 22.12。依赖具体解析版本由后续生成并提交的 pnpm-lock.yaml 固定。

## 3. 双端应用结构

- `apps/client`：唯一 React SPA，Web 与 Desktop 共用。
- `apps/desktop/src-tauri`：Tauri 桌面入口、权限和 SQLite migration。
- `packages/domain`：Task / Plan / WorkSession 领域实体和规则。
- `packages/application`：RingsService 与 Repository 接口。
- `packages/infrastructure-web`：IndexedDB Adapter。
- `packages/infrastructure-desktop`：Tauri SQLite Adapter。

不建立第二套 Web UI，也不在页面组件中直接写 SQL。

## 4. 持久化与同步

| 平台 | 数据存储 | 隔离范围 |
|---|---|---|
| Web | IndexedDB | 浏览器 Origin / 浏览器配置 |
| Desktop | SQLite | 本地 RINGS 应用数据目录 |

v1.0 不做自动云同步。Web 和 Desktop 的数据不会自动互通；未来通过显式 JSON 导出 / 导入交换，导入需预览映射、冲突和备份。

## 5. 业务约束冻结

1. Task、Plan、WorkSession 是三个独立实体。
2. 一个 Task 可以有多个 Plan。
3. Deadline 不属于 Plan。
4. 取消 Plan 不删除 Task 或 WorkSession。
5. Plan 冲突默认提示；用户确认后可以保留重叠，不自动重排。
6. 每个 Task 同时最多有一条未结束 WorkSession。
7. WorkSession 实际时长以 startedAt / endedAt 计算，不使用 Plan 时长代替。
8. Task 软删除可恢复；关联 Plan 和 WorkSession 保留。
9. v1.0 暂不开放永久删除，避免误删历史数据。
10. Goal / Stage 日期不自动级联修改 Task Plan。

## 6. 安全和平台边界

- Tauri 使用 Capability 明确授权 SQL Plugin 所需操作。
- SQL 访问封装在 Desktop Repository Adapter。
- Tauri 配置启用受限 CSP；不加载远程脚本和 CDN 字体。
- Web 只使用浏览器授权能力，不承诺任意本地路径访问。
- 本地文件 / 文件夹能力后续通过平台 Adapter 添加，默认不递归扫描或自动上传。

## 7. v1.0 首个纵向闭环

创建 Task → 创建 Plan → 冲突检查 → 开始 WorkSession → 结束并记录实际时长 → 完成 Task → 重启后恢复数据。

首个代码骨架已建立，当前实现范围包括 Task 创建 / 完成 / 软删除 / 恢复、Plan 创建 / 取消 / 冲突提示、WorkSession 开始 / 结束，以及两端本地存储适配。

完整 Task 编辑、Subtask、调度首页时间线、甘特图正式数据接入、Candidate、Goal / Stage、Habit、Review、备份和安装包仍未完成。
