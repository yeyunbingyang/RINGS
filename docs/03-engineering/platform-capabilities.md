# Desktop / Web 平台能力边界

## 1. 共用部分

- 领域模型和业务规则。
- Candidate / Goal / Stage / Task / Habit / Plan 等核心用例。
- 状态流转。
- 计划与实际记录语义。
- 基础搜索和关联模型。
- 数据导出格式（具体实现待定）。

## 2. Desktop 专属或优先能力

- 文件选择器、文件夹选择器。
- 打开本地文件和文件夹。
- 网络共享路径。
- 本地数据库。
- 系统通知。
- 系统托盘。
- 全局快捷键。
- 悬浮计时器。

系统托盘、全局快捷键和悬浮窗来自历史桌面端需求，当前属于增强能力，需在版本范围确认后实施。

## 3. Web 能力

- 网页 URL。
- 用户主动上传文件。
- 浏览器授权范围内的文件选择。
- 远程存储（若后续确定）。
- 不承诺直接读取任意本地绝对路径。
- 不承诺像 Desktop 一样任意打开本地文件夹。

## 4. 路径与外部引用

路径类型建议区分本地绝对路径、相对路径（依赖工作区根目录）、网络共享路径、URL 和自定义 URI。

跨设备时，本地绝对路径可能失效。若未来需要多设备同步，应设计路径映射或共享目录机制。

## 5. 权限与隐私

- 只访问用户明确选择的文件。
- 不默认递归扫描文件夹。
- 不自动上传外部引用指向的文件。
- 不执行未知文件。
- 失效引用保留元数据。
- AI 读取或自动识别文件必须有明确授权和范围。
