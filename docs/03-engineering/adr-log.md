# 技术架构决策记录（ADR）

> ADR 记录技术实现决策；产品语义决策见 `06-governance/decision-log.md`。

## ADR-001：Desktop / Web 共用领域模型

- 状态：已采纳为产品架构约束
- 背景：产品需要支持 Desktop / Web。
- 决策：核心业务模型和业务规则共用，平台能力通过适配层实现。
- 影响：文件访问、通知、系统托盘等平台能力不能直接写入领域层。

## ADR-002：本地数据库选型

- 状态：待决策
- 当前建议：Desktop 优先评估 SQLite。
- 未确认：Web 存储、迁移框架、同步机制。

## ADR-003：文件附件与外部引用分离

- 状态：逻辑决策已采纳，物理实现待设计
- 决策：附件副本与 URL / 路径引用必须有明确存储语义。
- 影响：备份、删除、预览、权限和跨设备策略不同。

## ADR-004：Plan 与 WorkSession 分离

- 状态：已采纳为领域约束
- 决策：Plan 是预定安排，WorkSession 是实际执行。
- 影响：统计不能用计划时长替代实际时长。

## ADR-005：云同步不作为当前基线

- 状态：已采纳为当前范围约束
- 决策：先建立本地优先和可导出数据结构，不把云同步作为首版前置条件。
- 影响：后续同步需增加冲突解决、身份和路径映射方案。
